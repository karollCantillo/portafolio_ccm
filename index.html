Sobre mí

Estudiante de Ingeniería de Sistemas en la Universidad Simón Bolívar. Me muevo entre el análisis de datos, redes y ciberseguridad, y también programación web — este portafolio es mi proyecto parcial de Tecnologías Web, hecho con HTML semántico, CSS con Flexbox y JavaScript sobre el DOM.
